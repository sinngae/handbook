# 风险和机会
+ 越是多赢的局面，约可能是个机会；
    + 如何评估一个事对多少人有利
    + 只有你占尽便宜，肯定不是机会
+ 结硬寨，打呆仗，才能走得更远
    + 开头容器做，就红到炸，越来越没劲 == 陷阱
    + 开头特别难，越干门槛越高 == 机会
+ 他人鸿毛，你的泰山
    + 对他人来说，只是兼职副业、锦上添花；对你是全部努力、全部身家 == 风险极大
+ 开始后，帮你的人越来越多 -- 大家都看得到的机会
    + 只是赞成，没有行动 -- 大家看到了风险、看不清楚、看出了问题，机会渺茫
+ 顺势发生的事，容易成为一个低风险机会；
因资源而启动的事，容易反转成陷阱； == 宁缺毋滥，追求的是资源，收获的是污染物。
但资源还是要追求。
+ 推动社会新分工的事情，越来越多人可以依赖它养家一辈子，机会
+ 能结出果子，还得能保住果子。自成体系、有城防 才不会被偷。
+ 就算不成，也长本事长江湖地位的事 == 机会；做成了，也有后遗症 == 陷阱；
+ 明牌了，也能干 == 机会； 唯恐别人知道的 == 陷阱
+ 孩子长大后也会为你骄傲的事 == 机会
