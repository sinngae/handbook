# 1. 时间失感和错觉
人生百年，三万多天，如此漫长又短暂，原来荒诞。

时间飞逝，一去不返。回头再干，不过是不够重要。
明日复明日，好似永远有明日，你是在许愿么？只是对时间麻木了。

没有所谓的时间管理，仅仅有的是活着。（活着，是忍受vs 还是享受）

大脑通过记录新的经历来度量事件，而自动跳过记录重复的经历，新鲜事物比重复旧事物给大脑带来更多刺激。
所以，对于每天都算是接触新事物的孩子感觉时间很慢，而每日例行公事的成年人则时间飞逝。对于成年人，这是一种Time Blindness 时间失感。

把每一天过的不同，或者 与重复的每一天平和相处。西西弗斯明知一次次重复推石头，如何？

时间错觉，人容易高估一天能做的事务，却低估一年能做的事务，所以容易追逐眼前目标、放弃远期目标。

# 2. 身体健康与活力，大脑健康与精力
健康包括长寿、身体活力、大脑精力。

睡觉，是恢复活力和精力的超能力。
每一天，如果早晨大脑如暴君般计划，那么白日里大脑如乱臣般执行。

微型锻炼，保障身体活力和大脑精力。
人的身体是为运动而生，而不是做几个小时。运动带来身体活力、思维清洗、大脑精力，微型锻炼低投入高产出。

人是丰富感官的生物，是感受的存在，打开每一种感官，和更大的存在、和整个世界连接。

## 取舍
精力水平比有时间更重要。没有精力的大脑就像醉酒状态，无法决策。
没有精力管理的时间管理是不会有用的。而每天的每个决策都需要消耗精力。
意志力是表演（是强者向他人投射的形象），需要精力支撑。聪明人不会依赖所谓的意志力，而是把精力留给重要的决策。

有些事务消耗精力，有些事务启动精力。

学习也需有取舍，不要试图在所有事情上都优秀，聪明人会选择在某些事上保持战略性糟糕、慎重的业余。把大脑的空间留给更重要的知识，并保留一份自我审视。

聪明的人会在不重要的事务上做战略性无能，知道何时放弃，战略性放弃、退出并不是失败，而是为了更好的机会留下空间。
对你的成长健康有害的事情要坚决放弃，无害也无益的事物快速放弃（选择性？）。


正其意不唯其利，明其道不急其功。

## 优先级管理
忙碌不见得高效。（用临终考验检测一下每天的所谓的事情）
写下一串要做的事，非Top3的就是你避免要做的事情。
无情地消除非必要事务，这一生能做好Top3已经很难了。

Top3小额的日常投入，随着时间复利收益倍增。

# 情绪
产生剧烈情绪的化学物质（如愤怒、恐惧、沮丧）会在身体中持续存在90s，而这之后由你选择。
你无法控制第一波情绪，但是绝对能控制住第二波情绪。

把控制住第二波情绪当作一种超能力。
人们会信任那些在混乱中保持冷静的人。

些许脆弱流露在正确的时间，可以构建更深的信任，而不是完美。

不要因为情绪，总是回避困难的对话。
困难对话的拖延就像高息债务，越是积压越是增加。你回避的小问题，每一天都在长大。
感恩表达让人感受良好，未表达的感恩就像一扇破窗，时间越久损失越多。

每个人都有脾气和情绪，不能一味的压制 或者 一味的放纵，可以尝试有控制的失控。

不卑不亢。
卑者，位置低、衰弱，自认为或自置于底下地位。
亢者，颈项，咽喉要害之地、身体之高处，自认为或自置于高等地位。

# 人生观度、世界的冷漠 和 那些不冷漠
无法说人生一定如何，但人生绝不是制作一张完美规划。
不要高估人生规划，却低估了测试。人生绝对需要运行一个个小实验，来测试那些对你实际有效的。
无需搞清楚一切再出发，人不能只靠思考就过上想象的生活，只能通过实践来检验人生的道路。

是否可以把人生当作一个作品集，收集着金钱、经历、人际关系、技能、梦想......

微小的调整，积累可成伟大的成果。
每一次小赢，都是为超脱人生贡献一份动量。

人类苦苦渴望获取人生的意义，而世界毫无反应的冷漠，而社会则反应荒诞。
那些看似热情的围绕着人类的信息，却构造成一个茧房。

摆脱那些所谓的社会标准，你的人生只能由你设计度量指标。
每月定期检视可以规避年底的遗憾后悔。

# 心智模型
心智模型事人理解、解构现实的思维捷径，是快速响应、计算的模式，是总结凝练的套路。
类似迷宫中的地图，而不同于拥有的领土。

心智模型必然比现实简化很多，这是其本质决定的。
多模型、组合模型、多级模型、异构模型，是必须的。
你需要和其他人一样关注眼前的问题，更需要不同于他人 进入二次思考、长时思考、深入思考。

知识不是力量，理解才是，理解进而知行合一。
平凡人采集知识，聪明人采集思维模式。
比答案更重要的是问题的起源。

学习是个人的事，要想有所成，须从不求使人知开始。

# 创造力
创造力不是坐等的兔子，而更像是打开水龙头，刚打开是脏水（Bad Ideas）。
坏主意也是有用的，他们为好主意探测了现实，发现了关键诀窍。

不要试图等待最完美的主意，就像坐等清水，却不打开水龙头一样。
而且你必须要撑住那些坏主意。

创造力喜欢约束。
无限的选择，会使人陷入选择的迷宫，导致迷茫。
约束的选择，更能激发创造力，也更能展现创造力。

创造力和评价是互斥的，就像油门和刹车 不能同时踩下。
First Create, Judge later

记录总结你创造的一切，大脑作为一个创造力的肌肉，看到自己的进步才能变得更强大。
那些早期的糟糕尝试，是它进步的证明。

原创技能需要缘分，组合技能的创造独特的交集 也是创造力的超能力。

# 人际关系
随缘、惜缘、不攀缘

人际关系就像银行账户，每次微小互动都是存款或取款，一个小赞美、一次迟到。
没有存款就无法取款。

有种人永远不明白：只在需要的时候联系他人，却不明白为何让他人心烦。

有些人只关注大手笔、大格局，昂贵的礼物、盛大的庆祝。而事实上，小小的日常存款更重要，随机的询问短信、记住小细节、在困难时候的相伴。

共同的痛苦比共同的快乐能够建立更牢固的纽带，一起面对挑战比仅仅玩乐更能创造深层次的联系。

不要忽视弱性联系，那些泛泛之交和疏远的朋友，他们是你通往新机会、新想法和新观点的桥梁。
强性联系使你舒适，弱性联系会帮助你成长。

想要扩展时间，帮助他人！给予时间会让你觉得时间更多了。

## 社会资本

成功不只是你所知道的？，也是你所认识的人。
社交不是采集商业名片或linkin联系方式，而是建立真正的人际关系。

一个简单的友谊公式：时间+脆弱性+共同经历。这些要素都是必要的，不可短缺。

“我没有时间去建立人际关系”，这种观点搞错了重点。
建立人际关系不是为了得到，而是为了连接connecting。最好的人际关系，不是收集者，而是连接者 connector。
连接者介绍应该认识的人互相认识。

有些人在维护友谊放面投入不足，他们想等待人生事件来重连他人。
但牢固的关系是在微笑的瞬间建立的，突然询问的短信、短暂的咖啡时刻。

如果社区是一个花园，你无法期待把所有种子种下就完事，你需要持续不断地呵护，每次对话、每次介绍。
成功的人在适用之前就开始构建自己的社区了，当你发现你需要社区的时候再构建就晚了。

金钱追随知识，总是如此。

忘掉职业阶梯吧，那就是个陷阱。
现代职业就像个游乐场，横向、斜向、倒退都可运动，每一步都应培养出独特的技能组合是你不可替代。

舒适的工作会不会是一个职业泥潭？
在一个你已经超越的角色上待得越长，离开越难。

当你回避一个工作任务时，转变为学习新事务。

# 财务智慧

金钱不只是银行账户上的一个数字，它涉及更珍贵的东西，你的时间自由。

赚取更多的钱通常让你的时间更加贫乏。
随着收入增长，一个人的生活方式也膨胀了。大房子=》更多维护；豪车=》更多担心；更好的邻居=》更长通勤时间。
“终于，我能买到我想要的一切了”，其中藏了一个陷阱，生活的膨胀扩张占据了你的时间。

真正的时薪包括了为了这笔钱牺牲的一切。
大多人购买商品，租售经验；而聪敏人租售物品，购买经验。
因为经验会增值，而物品通常不会。

一个财务技巧，Building Margins。
构建盈余，留有余地。
生活在你的能力之下，量入为出，并不是极尽节俭，而是为机会留有空间。
这个空间时通往财富的门票。
