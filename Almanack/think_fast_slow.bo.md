Think, Fast and Slow
---
“快思” 是直觉的、是冲动的，是自动化的思想，是自由联想的能力，容易凭感觉、凭印象下决定。倾向于专注特例而忽略整体观，并专注在容易记住的事情上，故容易形成偏见或刻板印象。

“慢想” 的能力可经由学习训练来建立。是透过理性的自我控制去刻意思考，可填补快思的副作用。倾向于用过去主观的经验来推演现在，会透过比较与规则来思考。以书面列出各种想法，可以帮助“慢想”做得更好。

# cpt-1 系统1 & 系统2
系统1 - 快思考
+ 直觉思考、习惯，自主运行
+ 应对危机

系统2 - 慢思考
+ 计算和推理思考
+ 需要集中注意力，人们天性懒惰

+ 系统1无法关闭 => 学会怀疑
+ 系统1失效，系统2默认启动
+ 系统1 导致 系统2 懒惰
+ 系统2 通过经常使用，而迁移到系统1
+ 系统2 需要集中注意力，从而忽视了其他信息，可能是很重要的信息。
+ 自我损耗，刻意掌控意志和进行自我控制很幸苦
    + 强迫去做自己不喜欢的事，很难自我控制
    + 补充葡萄糖可以恢复自我损耗
+ 头脑清楚的时候，两个系统都在活跃

# cpt-4 简化问题

+ 系统1 让人们往往会首先选择相信陈述句
    + 如 白鱼吃糖果、母猪上树
+ 系统2 让人们怀疑
+ 当系统2 繁忙时，人们会相信所有事情
    + 如 人是火焰
    + 人在精神劳累的时候，更容易相信那些空洞又有些说服力的信息，如广告、夜晚直播带货
    + 不要在晚上做决定
+ 替换，启发式问题与答案

    + 为了回答一个抽象问题，先提出一个具象问题

    + 启发式问题与答案，导致问题没有真正解决；也导致了偏见

# cpt-5 启发法和偏见
大数法则 与 小数定律

随机变量在大量重复实验中呈现出几乎必然的规律，样本越大、则对样本期望值的偏离就越小。

比如，抛硬币的期望值是0.5，单某次的概率就是0或1。多次的结果慢慢趋近于0.5 。

而人们往往缺少统计学习的训练，忽视了样本的大小，认为小样本和大样本具有相同的期望值。

比如，业绩好可能和行情有关，而不是领导的能力。
比如，赌徒总觉得自己下一次应该是多少，而下一次和之前的都没有关系。

+ 系统1 主观地关联了因果关系
+ 小样本的数据，来做大范围的回答
    + 一竿子打死一船人
+ 锚定效应 第一印象拟定答案
    + 打折促销，给人一种占到便宜的印象，而忽略了对方的底价
+ 可得性启发法、可得性偏见
    + 如，最近做飞机不安全，实际飞机事故率一直很低
    + 可得性效用会使事情夸大地更严重
+ 效用层叠，一连串的自持事件
    + 有人专门负责透消息，“可得性专业户”（水军）负责刷量，最终加速增强影响，最终重大媒体事件
    + 对于风险的处理是有限的，人们要么完全忽视；要么过于重视风险，没有中间地带

# cpt-6 偏见
典型性启发法
0. 通过少量特征就判断；第一印象；比乱猜可能更准确。
1. 让人忽略了基础比率信息，可能选择了错误的预测特征；人们喜欢典型性来预测，预测出的结果常是不可能发生的事情
2. 对证据不够敏感

合取谬误
+ 事件越具体，发生的概率越低
    + 事件越具体，人们越容易相信，也更不可能是事实
+ 两件事同时发生的概率会更低

回归均值
+ 表现与奖惩不一定有关系，可能只是运气好坏。
    + 一个人的付出一定的情况下，成绩时好时坏
+ 结果总是在均值附近扰动，与奖罚机制无关
+ 合理的期望值，应该基于均值
    + 如，股票；如，孩子的成绩；

书籍推荐《《如何独立思考》》

# 快思
1. 特色：
+ 来自自动化、印象、感觉、天生共有的技能、联想能力、直觉、冲动。
+ 建议用“慢想”来补足“快思”（直觉、意图）的不足。

2. 缺点：
+ 易有偏见。
+ 难以防止。
+ 倾向于回答“容易回答的问题”。
+ 无法被关掉。
+ 会专注在特定单一事件上。
+ 因为选择性记忆、形成偏好的关系，会倾向于记住“容易回忆的”。
+ 消除过去的记忆时，等于降低过去经验的价值。

3. 会依循：
+ 关联性。
+ 去类比过去事件。
+ 注重特例，大于关注平均值。
+ 故事性，有故事性的内容会比较容易记住。
+ 技术。
+ 专业上的重复经验。
+ 内在的看法。

4. 会形成：
+ 促发下列的反应：
    + 如微笑、金钱、死亡、罪恶
    + 潜意识
    + 锚点 —— 相信这就是全部（可以调整的方法）
+ 会倾向于做“合理化”处理的情况：
    + 找出因果关系
    + 信息不足时
    + 骤下结论
    + 找出最可能的
    + 不会记住其他可能性
+ 依赖常模 —— 刻板印象
+ 产生月晕效应（是指在人际知觉中所形成的以点概面或以偏概全的主观印象）
    + 消息不足时会太过自信
    + 马后炮，会颠倒因果
    + 改成单项来评估会更准确
+ 出现框架效应——以为看到全部，会聚焦在“已经知道的事情”。
+ 忽略基线：
    + 可用性偏见，会受提取度影响
    + 受乐观程度影响
    + 忽略运气因素
    + 偏向控制性的错觉
+ 出现情意快捷方式，会依照感情来判断决定。
+ 出现表征快捷方式：
    + 依照外表＆行为来判断决定
    + 过度偏好不太可能会发生的事情会发生
    + 对讯息品质不敏感
+ 会骤下结论（效度的错觉）：
    + 认知错觉比视觉错觉更顽固
    + 每次评估极可能有不一样的结果
+ 产生沉没成本的谬误：
    + 不卖赔钱的股票
    + 做不常做的事情却失败了，会怪罪自己，会倾向保守
+ 跟人格特质有关。

# 慢想
1. 特色：
+ 来自：
    + 主观经验
    + “快思”不能作用时
    + 自我控制——需要专注力，专注时瞳孔会放大，也需要记忆力
+ 信念：因为无知、懒惰，故会支持“快思”的结论。
+ 需要改正依赖直觉下决定，要特意去选择答案。
+ 需要理性，但“理性不等于智力”。
+ 要小心翼翼，记住凡事都有不确定性、要保持怀疑的心。
+ 要改变“快思”的结果，你可以这么做：
    + 需要重新设定注意力、习惯性的记忆，要注意概率问题。
    + 记住你可以改变最后决定权。
    + 尽量事前检讨。
+ 你会处于“心流”状态——不花力气的专注状态，浑然忘我时。
+ 可透过下列方式来学习训练：
    + 及时回馈更可以培养成专家
    + 像商人一样思考
    + 放慢速度
    + 增加选项
    + 当观察者
    + 团体决策
    + 了解“如何下决定”的过程
+ 平时会懒得运作。
+ 会自我批评。
+ 会想要多一点选择。
+ 缺点：
    + 需要比较多的时间才能开始运作，导致无法执行例行性决定
    + 不知道什么是对的时候，就容易犯错
+ 会依循“规则”“比较”。
+ 生活满意度比较高，但生活满意度并不等于幸福感。
+ 青少年时期所建立的观念（金钱观、人生目标），会影响未来生活满意度。
