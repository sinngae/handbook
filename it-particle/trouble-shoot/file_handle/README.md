# Python 日志抓取脚本

功能说明：

1. 读取多个有序日志文件（按文件名顺序）
2. 匹配规则：
   - 日志行包含 `error` 或 `err`（大小写不敏感）
   - 提取编码：`TN`开头，后面跟数字，总长度 = 20 位
   - 正则规则：`TN\d{18}`  TN+18 个数字，合计 20 字符
3. 输出结果：去重，保存到结果文件

## 使用说明

1. 修改 `log_files` 列表，**按日志时间顺序填入日志文件路径**
2. 编码规则：`TN` + 18 位数字，总长度严格 20 字符，例如 `TN123456789012345678`
3. 匹配 `err/error` 不区分大小写，Error、ERROR、Err 都可以命中
4. 自动去重，相同编码只输出一次
5. `errors="ignore"` 防止日志有乱码导致读取崩溃
