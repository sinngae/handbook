# Go 值类型 vs 引用类型：本质一句话
> **Go 没有引用类型！Go 所有变量都是值传递。**
> 我们口语说的“引用类型”（slice/map/chan/func/interface），本质是**内部封装了指针的值结构体**。
>
> 区分：
> - 值类型：变量直接存**数据本身**
> - 口语里的引用类型：变量存的是**一个小结构体，结构体里面带着指向底层数据的指针**，变量本身依然是值。

> 很多教材说 Go 有引用类型，这是**简化说法**；从语言规范层面，Go 不存在 C++ 那种引用（reference）。

## 一、值类型（直接存数据）
包括：`int`、`bool`、`float`、`struct`、`array`（数组！不是slice）。
变量内存里放的就是完整数据。
赋值 / 传参时：**完整拷贝一份数据**。

```go
a := 10
b := a // 拷贝值，a,b互相独立
b = 20
// a 仍然是10
```

数组例子：
```go
var arr [3]int = [3]int{1,2,3}
arr2 := arr // 完整拷贝整个数组，不是共用底层
arr2[0] = 99
// arr[0] 不变
```

结构体同理：赋值拷贝整个结构体。

## 二、口语“引用类型”：本质是【带指针的header结构体】
`slice` / `map` / `chan` / `function` / `interface{}`
变量本身不是指针，但**变量内部包含指针字段**。
赋值/传参：**拷贝这个小header结构体（里面拷贝指针），底层数据共用。**

### 1. slice header（伪代码）
```go
type slice struct {
    ptr unsafe.Pointer // 指向底层数组
    len int
    cap int
}
```
`var s []int`：s 就是这个结构体。
当 `s1 := s`：拷贝 ptr、len、cap。**两个slice的ptr指向同一个底层数组**。
所以修改 `s[0]`，两个slice都看到。
但是：`s1 = append(s1, ...)` 如果触发扩容 → ptr 变了，不再共用。

### 2. map header
```go
type maptype struct {
    hmap *hmap // 指针指向哈希表
}
```
`m1 := m`，拷贝的是 hmap 指针，共享同一个哈希表。

### 3. chan header
```go
type chan struct {
    hchan *hchan
}
```

> 关键点：拷贝的是**header（里面的指针）**，不是拷贝底层大的数据。
> 所以看起来像“引用传递”，但底层依然是**值拷贝**。

## 三、最容易踩坑的对比代码
### 场景1：map（共享底层）
```go
func modify(m map[string]int) {
    m["a"] = 100 // 修改底层hmap，外面能看到
    m = make(map[string]int) // 仅仅修改函数内副本的header指针，外面m不受影响
}
```
✅ 修改底层数据：外部可见
❌ 给参数变量重新赋值：只改副本，外部看不到

### 场景2：slice
```go
func modify(s []int) {
    s[0] = 99 // 修改底层数组，外部可见
    s = append(s, 100) // append修改副本slice的len；扩容则修改副本的ptr，外部s不受影响
}
```

### 场景3：值类型 int
```go
func modify(x int) {
    x = 100 // 修改副本，外面不变
}
```

## 四、指针类型（单独一类，不要和“引用”混淆）
`*int`、`*struct{}` 这是**指针类型**。
变量存的就是内存地址。赋值/传参拷贝地址。
> 指针 ≠ 口语引用类型
> - `*int`：变量直接就是指针
> - `[]int`：变量是结构体，结构体里面藏指针

```go
a := 10
p := &a // p 是 *int，变量p直接存a的地址
```

## 五、总结表格
| 类型 | 变量内存存放内容 | 赋值/传参行为 |
|---|---|---|
| 值类型 int/struct/array | 完整数据本体 | 拷贝全部数据，底层不共享 |
| slice/map/chan（口语引用） | header结构体，内部含指针 | 拷贝header，底层数据共享；重新赋值变量只修改副本 |
| 指针类型 *T | 内存地址 | 拷贝地址，指向同一个对象 |

## 六、面试高频一句话考点
1. Go 所有传参都是**值传递**，没有引用传递。
2. slice/map/chan 不是指针，是**包含指针的结构体**。
3. 所谓“引用效果”只是因为拷贝出来的header里的指针指向同一个底层数据。
4. 函数内对 slice/map 参数**直接重新赋值**，外部不会变化；修改其底层数据，外部才会变化。
