# 全文索引
MySQL 5.6 之前，只有 MyISAM 存储引擎支持全文索引。
从 MySQL 5.6 开始，InnoDB 也支持全文索引。全文索引仅适用于 CHAR、VARCHAR 和 TEXT 类型的字段。
MySQL 5.7.6 引入了 ngram 分析器，支持中文、日文和韩文的全文检索。

## sql
```sql
-- 创建
create fulltext index idx_ft_demo on tbl; 

-- 使用
select * from user where match(name) against('aaa');


-- 查看配置
show variables like '%ft%';

```

+ 默认分词间隔符" +-><()~*:\"&|"
+ 默认word最小最大长度 4~84，这个长度限制的才有效
+ 默认token最小最大长度 3~84
+ 。。。
