# DoS/DDoS攻击解析与防护

**DoS（拒绝服务）**攻击通过大量恶意请求耗尽目标系统资源，使其无法响应合法用户请求；
**DDoS（分布式拒绝服务）**则利用分布在全球的受控设备（僵尸网络）同时发起攻击，流量来源分散，防御难度更高。

## 核心原理包括：
+ 流量耗尽：如UDP洪泛、ICMP洪泛，直接堵塞带宽。
+ 协议滥用：如SYN洪水、Smurf攻击，耗尽连接队列或网络设备处理能力。
+ 应用层消耗：如HTTP洪水、CC攻击，通过频繁复杂请求拖垮应用服务器。

## 典型攻击流程：
+ 构建或租用僵尸网络：感染PC、IoT等设备，形成可远程操控的攻击源。
+ 发起攻击：向目标IP发送海量请求或数据包，可能伴随IP伪造与反射放大技术。
+ 可能的掩护作用：在DDoS掩护下实施数据窃取或勒索软件攻击。

## 常见防护策略：
+ 网络层防护：部署防火墙、IDS/IPS过滤异常流量；利用流量清洗中心剔除恶意流量。
+ 应用层防护：使用WAF阻断恶意HTTP请求；设置速率限制防止单IP高频访问。
+ 分布式防护：通过CDN分散访问压力，隐藏源站IP；负载均衡将流量分配至多台服务器。
+ 云防护服务：如阿里云DDoS高防、AWS Shield，提供大规模攻击的实时监测与自动缓解。
+ 监控与响应：实时监控流量基线，异常时快速切换高防IP或启用清洗服务。

## 实战建议：
+ 事前：梳理核心业务与端口，预留冗余带宽，制定应急预案。
+ 事中：根据攻击类型调整防护策略，优先在上游（ISP/CDN）拦截流量。
+ 事后：分析攻击日志，溯源并修复漏洞，防止设备被控为肉鸡。

通过构建“监测—过滤—清洗”的多层防护体系，可显著降低DoS/DDoS攻击带来的业务中断与经济损失。
