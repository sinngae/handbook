analyzer
----
+ 索引文档时，将text类型的字段做分词然后插入倒排索引
    + 索引时，先看定义的analyzer，没有则看ES预设的
+ search_analyzer，在查询时 先对要查询的text类型的输入做分词，再去倒排索引
    + 查询时，先看定义的search_analyzer，没有则去看analyzer，再没有则取ES预设的

# 内置analyzer
+ 分析器，Analyzer
    + 处理文本数据
    + 包括 分词器 和 标准化
    + 分词器
        + 自带
            + Custom，自定义分词，可组合多个tokenizer、char filter、token filter满足特定需求
        + 需安装
            + IK，开源Java中文分词，细粒度和最大词长两种切分模式，支持用户词典扩展定义
            + jieba，中文分词和词性标注，实用Python
            + THULAC，清华NLP的中文分词，中文分词、词性标注
            + Pinyin，拼音分词，中文文本转成拼音形式
+ standard，默认的分析器，基于Unicode文本分割算法，对大多数语言有效
    + Standard，小写处理、去除停用词和标点符号
+ simple，简单分析器，放弃非字母字符、如数字/空格/连字符等，大写改成小写
    + Simple，通过非字母字符分割文本、词汇统一小写形式、去除数字类型
+ whitespace，空格分析器，放弃空白字符，分解为术语
    + Whitespace，仅去除空格，不做小写处理，不支持中文，不做其他规范化
+ stop，停止字分析器，默认使用_english_停止词，删除停止词、如the
    + Stop，去除英文中的常用单词（如 the、a），不支持中文
+ keyword，不分词，把整个字段当作一个整体词
    + Keyword，不分词，适用于索引和检索特殊类型的文本信息，如邮政编码、地址等
+ pattern，模式分词器，使用正则表达式分词拆分
    + Pattern，使用正则表达式拆分词元，接收lowercase/pattern/flags/stopwords等
+ Language，30中常见语言的分词器，没有中文
    + 多种西语系分词器，arabic、bengali、dutch、english

# 中文分词器
+ elasticsearch-pinyin
    + 拼音匹配文字
+ ik分词器
    + ik_smart，简单中文分析器，支持自定义字典、远程字段
    + ik_max_word，全量分词器，更多分词
+ jieba分词器
    + 精确模式，最精确地分词；全模式，按词分、不能消除歧义；搜索引擎模式，在精确模式上对长词再切分、提高召回率，适用于搜索引擎分词
    + 支持繁体分词
    + 支持自定义词典
+ THULAC
    + THU lexical Analyzer for Chinese，清华大学自然语言处理与社会人文计算实验室
    + 中文分词和词性标注
+ NLPIR
    + 中科院计算所 分词
+ word分词
    + java实现的基于词典的分词算法，使用ngram模型来消除歧义

# 自定义分析器
+ 0个或多个character filter 字符过滤器，过滤掉规则匹配的无效字符 并 分成块
+ 内建 char_filter
    + html_strip，html字符过滤器，过滤掉标签、解码反义
    + mapping，映射字符筛选器，按kv映射、有限最长的匹配映射
    + pattern_replace，正则匹配 替换指定字符
+ 1个分词器 tokenizer，分词
+ 内建 tokenizer
    + char_group，按定义集合中的字符 把文本分解为术语
+ 0个或多个token filters，每个分词再过滤

# ngram分词器
+ NGram分词器 是ES自带的具有前缀匹配搜索功能的一个文本分词器，能根据文本的步长逐步（滑动）对写入的文本内容进行约束切割。
+ type可为 edge_ngram / ngram，前者带着首字符逐个匹配、后者全字符逐个匹配
+ 默认 min_gram和 max_gram为不大于1，也就是按照一个字符逐个分词
