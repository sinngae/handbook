# 详细的文件类型
Elasticsearch（ES）在磁盘上会生成多种类型的文件，这些文件共同构成了ES的索引和数据存储结构。以下是一些常见的文件类型及其作用：
+ 1. 索引元数据文件
这些文件存储了索引的元信息，包括索引的配置、映射（Mapping）等。
- `index` 文件
  - 作用：存储索引的元数据，包括索引的名称、版本、映射（Field Mappings）、设置（如分片数、副本数等）。
  - 位置：位于索引目录的根目录下，通常是一个JSON文件。
- `index-uuid` 文件
  - 作用：存储索引的唯一标识符（UUID），用于在集群中唯一标识一个索引。
  - 位置：位于索引目录的根目录下。
+ 2. Segment 文件
Segment 是ES中存储数据的基本单元，每个Segment由多个文件组成，这些文件存储了倒排索引、文档存储、Doc Values等数据。

- `.si` 文件（Segment Info）
  - 作用：存储Segment的元信息，包括Segment的名称、版本、包含的文档数量、删除文档信息等。
  - 位置：位于Segment目录下。

- `.cfs` 和 `.cfe` 文件（Compound File Segments）
  - 作用：`.cfs`文件将多个Segment文件合并成一个单一的文件，以减少文件数量并提高性能。`.cfe`文件是一个索引文件，记录了`.cfs`文件中各个小文件的偏移量和元信息。
  - 位置：位于Segment目录下。

- 倒排索引文件
  - `.tim` 和 `.tip` 文件
    - 作用：`.tim`文件存储了倒排索引的主体内容，包括词汇表（Term Dictionary）和倒排列表（Postings List）。`.tip`文件是一个索引文件，用于快速定位`.tim`文件中的词汇位置。
    - 位置：位于Segment目录下。
  - `.fdt` 和 `.fdx` 文件
    - 作用：`.fdt`文件存储了文档的字段值，`.fdx`文件是一个索引文件，用于快速定位`.fdt`文件中的文档位置。
    - 位置：位于Segment目录下。

- Doc Values 文件
  - `.dv` 文件
    - 作用：存储了Doc Values的数据。Doc Values是以列式存储的方式组织的，每个字段的值都存储在一起，便于高效读取和处理。
    - 位置：位于Segment目录下。

- 其他文件
  - `.del` 文件
    - 作用：记录删除文档的位图，标记哪些文档已被删除。
    - 位置：位于Segment目录下。
  - `.nvd` 和 `.nvm` 文件
    - 作用：存储规范化因子（Norms），用于评分时的规范化处理。
    - 位置：位于Segment目录下。
  - `.tvf`、`.tvd` 和 `.tvx` 文件
    - 作用：存储词项向量（Term Vectors），包含词汇的词频、位置和偏移量等信息，用于支持复杂的查询操作。
    - 位置：位于Segment目录下。
+ 3. 事务日志文件（Translog）
Translog用于记录索引操作的事务日志，确保数据的持久性和一致性。
- `translog` 目录
  - 作用：存储事务日志文件，记录所有未提交的索引操作（如新增、更新、删除文档）。在索引操作完成后，这些操作会被写入Translog，直到数据被刷新到Segment文件中。
  - 位置：位于索引目录下的`translog`子目录中。
  - 文件格式：通常以`.tlog`为扩展名，例如`00000000000000000001.tlog`。
+ 4. 其他辅助文件
- `segments_N` 文件
  - 作用：存储当前Segment的列表和状态信息，其中`N`是一个版本号。这个文件用于管理Segment的生命周期，包括哪些Segment是活跃的、哪些已经被删除等。
  - 位置：位于索引目录的根目录下。
- `write.lock` 文件
  - 作用：写锁文件，用于防止多个进程同时写入同一个索引目录，确保数据的一致性。
  - 位置：位于索引目录的根目录下。
+ 文件结构示例
假设你有一个名为`my_index`的索引，其在磁盘上的目录结构可能如下所示：

```
my_index/
├── _state/
│   ├── index
│   └── index-uuid
├── _translog/
│   ├── translog-00000000000000000001.tlog
│   └── translog-00000000000000000002.tlog
├── _0.cfs
├── _0.cfe
├── _0.si
├── _0.tim
├── _0.tip
├── _0.fdt
├── _0.fdx
├── _0.dv
├── _0.del
├── _0.nvd
├── _0.nvm
├── _0.tvf
├── _0.tvd
├── _0.tvx
├── segments_1
└── write.lock
```
+ 总结
Elasticsearch在磁盘上生成多种类型的文件，这些文件共同构成了索引和数据存储结构。主要包括：
- 索引元数据文件：存储索引的配置和映射信息。
- Segment文件：存储倒排索引、文档存储、Doc Values等数据。
- 事务日志文件（Translog）：记录索引操作的事务日志，确保数据的持久性和一致性。
- 其他辅助文件：如Segment列表文件、写锁文件等，用于管理索引的生命周期和数据一致性。

这些文件的组织和管理方式确保了Elasticsearch能够高效地存储、检索和管理数据。
