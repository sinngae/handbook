## 代理
**正向代理/反向代理**  
正向代理，即翻墙/隐藏客户端访问路径/堡垒机安全访问/VPN专线访问。
反向代理，保护或隐藏网络服务或资源/加密和SSL加速/负载均衡/缓存CDN/压缩/减速上传/安全/外网发布。
区分正向代理还是反向代理的关键不是是否在同一局域网或防火墙前后，而是代理的目的或为谁服务。

### nginx
高性能 HTTP 服务器和反向代理，现可作为负载均衡器、静态文件服务器、缓存服务器和 API 网关使用。其配置采用类似编程语言的文档结构，易于理解和维护，支持丰富的第三方模块和社区资源，但高级功能（如会话保持、健康检查）可能需要商业版或额外模块。
### haproxy
一种功能强大的负载均衡器，支持第四层（TCP/UDP）和第七层（HTTP/HTTPS）的负载均衡。它在处理高并发请求和复杂流量控制方面表现出色，提供丰富的健康检查功能，能够实时监控后端服务器状态并进行故障转移。HAProxy 的配置灵活，适用于需要高可靠性和精细化流量控制的场景，例如在线交易平台和社交媒体网站。
### lvs
基于 Linux 内核的负载均衡技术，工作在 OSI 模型的第四层（传输层），通过 IP 和端口进行流量分发。它的性能极高，接近硬件负载均衡，适合处理大规模并发连接。LVS 的配置相对复杂，主要适用于对应用层功能要求不高的场景，例如企业内部的邮件服务器或数据库服务器。LVS 通常与 Keepalived 搭配使用，以实现高可用性。
