线上问题排查
----

+ 问题定位和信息收集
    + 问题的描述，具体表现，如系统响应慢、服务不可用、数据异常
    + 影响范围，影响的用户群体、功能模块、服务
    + 时间点，发生时间，持续发生 还是 间歇发生的
    + 环境信息，收集系统环境信息，如服务配置、go版本、发版版本
+ 快速响应
    + 严重程度评估，影响范围、业务重要性，是否阻塞业务、影响金额、持续时间
    + 应急措施，回滚版本、限流、降级
+ 日志分析
    + 日志的错误分析、异常堆栈
    + OS日志，linux /var/log/messages
    + 中间件日志，DB 缓存、MQ、
