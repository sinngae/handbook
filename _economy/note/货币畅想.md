# 数字货币
限额的数字货币必然通缩。
不限额的没有信用或其他事物背书的数字货币必然难以获得信任。


# 电量货币
能源货币，以电量为例。
+ 难以方便地跨境流通、存储保值
+ 经济复杂性，生产成本、传输损耗、不同能源的转换效率，如同用米面买羊
+ 国际协调难度大，各国各地区能源分布不均衡

能源作为货币难度大，做全球的能源交易所还是可以的。
问题在于信任。。。。太难了。
