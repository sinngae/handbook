# 南北方经济差异
本案的南北方特指中国大陆的北方和南方

## 北方经济为什么不如南方
正确的观点有
+ 资源承载能力的区别
+ 与国际交流信息的延时
+ 改革政策的区别对待，侧重东南方
+ 港澳台/海外侨乡/东南亚的地缘优势

错误的观点有
+ 南方理念更先进
+ 北方人太靠关系

北方发展并没有落后，但发展更均衡(说不上好与坏)。

## 资源承载能力的区别
北方冬天冷需要供暖，全年干旱需要蓄水。水资源不多，需求却更大。油料、煤炭丰富，但环境代价较高
北方多平原，土地资源丰富。
南方水资源丰富，大城市可承载更多的人口。
