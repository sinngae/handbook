# 问题

历史经过
+ 20世纪初到1970年代之前，美国外贸整体处于平衡状态，部分时期有贸易顺差
    + 1945年前，经济危机、大萧条、一战、二战各国的进出口波动都非常大
        + 而美国奉行孤立主义、大发战争财，成为战争盟军的重要物资供应国
    + 1945年后，战后经济复苏与黄金时代
        + 美国大幅领先的工业基础和技术创新能力，成为全球最大的出口国（尤其是汽车、钢铁和机械等领域）
        + 同时美国积极推动全球自由贸易、马歇尔计划（帮助欧洲重建、重塑并拓展国际市场）
        + 美国总体上外贸保持顺差（有时较小逆差），直到1971年才首次出现较大逆差
+ 1970年代到1990年代初，经济结构调整与逆差扩大
    + 开始出现贸易逆差，并逐渐扩大
    + 石油危机、通货膨胀、传统制造业向服务业和高科技产业转型，同期石油进口大幅增加
        + 石油危机，中东战争（以色列VS阿拉伯，石油、运河）、伊朗政变和两伊战争
        + 美国国内石油资源枯竭，但工业化、城市化的快速进程急剧需要石油
        + 其他市场也在高速发展，竞争石油资源
    + 新经济体兴起，亚洲四小龙、德法工业，制造业、高科技产业竞争加剧
    + 1970s中期、1980s初期，逆差规模显著扩大
+ 1990s到2008年，全球化加速与贸易逆差持续扩大
    + 新兴经济体（金砖四国、欧盟、东南亚、中东、南美、俄罗斯、中国）都加入到全球化之中
        + 1990年，日本金融、房地产同时泡沫破裂，股市大跌、房地产降价、资本和资产外流；从此失落的三十年开启。
    + 美国的制造业进一步外移（不具备劳动力优势），导致对进口商品的依赖增加
    + 美国的金融市场开放，美元作为全球储备货币（地位稳固）
    + 逆差持续扩大，2000s初 逆差规模达到新高
+ 2008金融危机后至2018年，经济复苏与贸易政策调整
    + 2008金融危机，美国经济进入缓慢复苏阶段
        + 2008金融危机，美国房地产泡沫
            + 前期的各类金融创新（金融衍生品、CDO、CDS。。。）积累的金融风险，缺少管制
                + 金融工具分散了风险，也掩盖了风险
            + 利率波动时，大量房贷违约、房产被银行收回、银行坏账上升、抽贷其他产业、债务违约率进一步上升，形成恶性循环
            + 第四大投资银行，雷曼兄弟破产 引起全球金融市场恐慌
            + 金融机构倒闭、信用市场瘫痪、资金链断裂、股市暴跌
            + 全球贸易萎缩，
            + 新兴市场收到冲击，利润吸管被打破
        + 一系列经济刺激政策，量化宽松、贸易保护主义
    + 美国产业结构调整
        + 新能源、生物科技等新兴产业兴起
    + 经济危机后，逆差有所收窄；经济复苏后，逆差规模再次扩大
+ 2018年至今，贸易保护主义与全球供应链重组
    + 特朗普奉行贸易保护主义政策，对各国加征关税、对他国技术封锁和贸易限制
    + 新冠疫情和地缘政治因素发生重组
    + 贸易逆差在2022年达到历史新高，9481亿美元

#### 利润漏洞问题
如果一家上市企业高于市场价向一家私人企业采购某项资料或服务，这家私人企业将利益输送到个人口袋。那么上市企业的利润就被这种“利润吸管”吸取了。

+ 难以避免，本应属于其他股东和股民的利益就这样被窃取了
