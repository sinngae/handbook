Star法则
---
Star法则是面试官常用工具，用来收集面试者与工作相关的具体信息和能力。Star法则可以更精确地预测面试者未来的工作表现。
+ S -- Situation 情景
    + 事件发生的上下文情景
+ T -- Target 目的
    + 主体需要明确的目标
+ A -- Action 行动
    + 分析以及采用的行动方式
+ R -- Result 结果
    + 具体的结果

Star法则是一种讲述自己故事的方式，一个清晰、有条理的作文模板。

# 自我评价的抽象体系
脱离具体的人和事，避免陷入细节，形而上

+ 不要使用别人的现成的评价体系来替代自己的思考
    + 现代人思维方式的异化
        + 放弃自我思考，转到抽象体系替换自己的思考
        + 现代人对于自身生活状况更加缺少了解
        + 专家的判断 替代自我思考
        + 惰性思维 -- 分数、排名、收入
            + 使用单一的数字指标作为评判事物的标准
                + 丢失了分寸感的思维 --- 单一角度看事物
    + 你究竟是谁？你想要的是什么？认识你自己
    + 尤其是数字化，比如520的专业比500分的好；5k的工资比3k的工资好
    + 别人的抽象思考体系只是参考，不能替代自我思考
+ 提高自己的看待问题的颗粒度
    + 细化思考的颗粒度，从更细的层面分析事物
    + 找到正反馈
        + 越做越有成就感、更多积累 
+ 建立自我评判的抽象体系
    + 自我提炼出来的抽象层次
+ 信任自己的抽象思考能力
    + 从 感性思考 到 对待事情的分寸感的思考
    + 从认知自己和世界来，来清晰自己的目标，获取对未来的确定感和笃定
