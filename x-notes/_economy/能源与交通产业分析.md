# 动力形式
+ 内燃机+燃料，以汽油为例
+ 动力电池，以锂电池及后续固态电池为例
+ 氢燃料电池
+ 混合动力，组合形式

能量密度最高的是燃油和氢燃料（取决于储氢的技术）；
更易精细控制的是动力电池；
百公里燃油消耗 和 百公里 电能消耗，运算麻烦，但如果直接用百公里金额消耗更直观 却更不实用（便于对比、却不能适应变动中的价格）；
电动机效率可达90%，电池充放电 + 电动机 综合效率 70%-80%；内燃机效率最高 50%（本田、马自达发动机）


# 载具的交通介质
+ 船只水运，刨除洋流、顺流逆流影响
    + 同样的载重（满载而非空载）下，百公里消耗燃油略低
    + 更适宜大规模货物运输
    + 常见船只的航速普遍低于50公里每小时（快艇最快90，军舰最快74）
    + 动力主要克服水的阻力，很难降低能耗
+ 飞行器空运，刨除大气环流的影响
    + 同样的载重，百公里油耗比汽车高两倍
    + 更适宜时效性高的人货运输
    + 常见航速差异较大（km/h：evtol 500，民航1000，直升机300，超音速客机3000，战斗机3000）
    + 能耗，
        + evtol 31kWh/100km
        + 民航客机 3-5L 航空燃油
        + 直升机 10-15升燃油
        + 战斗机高速飞行百公里油耗（1马赫左右）约在 200~350升
        + 开启加力燃烧室，F-15战斗机 每小时油耗 8.1吨 歼20 每小时油耗33吨
        + 
    + 动力主要克服空气阻力，很难降低能耗
+ 汽车陆运，刨除人力、蓄力交通工具
    + 常见航速差异较大（电瓶车 40，摩托车120，汽车120， 高速列车350，磁悬浮 600， 货运列车 120，地铁 80）
    + 能耗差异也较大
        + 燃油，升每百公里：摩托车 3，轿车6-9，货车15-20， 公交车 8，
        + 电动，kWh/100km：轿车 15-20
        + 高铁（电力）：人均 21kWh/100km
            + 长距离客运 能耗低 效率高
            + 使用的是沿途的接触网供电，而不是动力电池
            + 也备有锂电池包，主要用于应急的照明、空调等电子设备
        + 货运列车，柴油：2.5L/100km
        + 地铁轻轨：10kWh/100km
        + 混动电车 5升百公里
        + 磁悬浮列车，与速度相关（350km/h 人均3.5kWh/100km，400 10, 600 ）
            + 350时速 能耗是高铁的15%
            + 400时速 能耗是高铁的70%
            + 600时速 能耗是航空的50%
            + 1000时速 能耗显著增加，接近航空
            + 磁悬浮是消耗一部分能量达到无接触运行、降低了机械摩擦，因此更低能耗
    + 
+ 骑马
    + 最高速度 60公里每小时（疾驰、可持续5min~8min，之后就会陷入更加疲惫、速度严重下滑）
    + 最好的马 耐力赛中  100公里也需要5小时，每天消耗 15-20公斤干草

（中国幅员辽阔，长宽面积平均 3000公里，实际南北、东西方向最长5000公里）
（各类能量价格：航空汽油通常按吨计价 6096每升，折合每升8元；汽车燃油一般不高于每升8元；居民电价各国各地差异很大，中国在每千瓦时 1元）

# 进一步分析

## 动力消耗
船只航速通常较低，空气阻力一般不考虑（风帆类、战舰类除外），主要是克服水流阻力。同样的陆地交通低速行使主要克服的是地面摩擦、机械内部摩擦。

+ 飞机阻力 接近100%来源于空气阻力
+ 汽车 100km/h运行，75%克服空气阻力；120 —— 80%；
+ 高铁 300km/h运行，90%是空气阻力

空气阻力（迎风面和背风面的压力差），与速度的平方成正比。
随着速度上升，主要阻力都是空气阻力。

列车可以造得很长，相对的迎风面积最小。
相比于流线型汽车，非继机翼、引擎都会产生巨大空气阻力（为了升力的牺牲），因此飞机的迎风面积最大、其能耗远远高于差不多大小的汽车的。

汽车的经济时速
+ 排量 1.2L 以下的汽车，经济时速约为50km/h
+ 排量 1.2L-1.6L 之间的汽车，经济时速约为 70km/h
+ 排量 1.6L-2.0L 之间的汽车，经济时速约为 100km/h
+ 排量 2.0L 以上的汽车，经济时速约为 120km/h

## 结论
+ 个人飞行工具只会比汽车更消耗能源，当然速度更快、体验更好。
+ 因此整体上，轨道交通效率最高、汽车次之、飞行工具最低。
+ 一个社会整体节约能源的最佳办法依然是乘用公共交通工具
    + 公共交通 比 个人交通更节能
    + 轨道交通比滚轮交通更节能，轮胎交通比飞行交通更节能




# 拓展
## 制约磁悬浮列车普及的因素
+ 技术因素
    + 悬浮控制技术复杂，需要精确控制磁浮力与导向力，以确保稳定的悬浮状态，在极端天气下难以保证（技术要求高）
    + 轨道与车辆耐久性问题，建设和维护复杂，轨道和车辆的耐久性需要进一步提升
        + 高架桥建设要求桥墩基础需要深达30米以上
        + 轨道两侧一定范围内不能有其他建筑物
    + 技术成熟度和稳定性不足，仍在不断发展和完善中
        + 超导材料的稳定性和耐久性、真空管道技术的可行性和安全性需要进一步论证和研究
+ 成本因素
    + 建设成本高，当前磁悬浮列车的建设和维护成本远高于传统铁路
        + 上海浦东磁悬浮线约30公里，设计投资 380亿元，且一直处于亏损状态
    + 运营成本高，磁悬浮能耗虽然低，但设备复杂、维护成本高，导致运营成本居高不下
        + 对安全和维护的要求也高
    + 投资回收周期长
        + 建设成本高、客流量有限，投资回收周期较长，投资风险较大
        + 例如，京沪高铁如果采用磁悬浮技术，预算成本将远高于现有的轮轨技术
+ 市场因素
    + 市场需求有限，当前需求主要集中在特定领域，旅游专线、机场联络线
        + 既有高铁和航空已经满足大部分出行需求，磁悬浮列车的市场空间较小
    + 公众认知度低？安全性、舒适性、经济性
+ 安全与环境因素
    + 安全性问题，磁悬浮列车的紧急制动能力相对较弱，发生事故救援难度大
        + 2006年 德国磁悬浮列车 严重事故，多人伤亡
    + 环境影响，环境景观、电磁辐射

## 制约低空小型飞行器普及的因素
+ 技术因素
    + 核心技术平静，关键技术 发动机、飞控系统、核心零部件等仍有短板
        + 我国在低空飞行器的主控芯片、智能仪器仪表和传感器等关键核心元器件尚未完全掌握自主，部分核心系统依赖进口
    + 续航与性能不足，电池能量密度、电机功重比等技术难题有待攻克（影响续航能力和负载能力）
        + 目前成熟的eVTOL电池能量密度仅为 285Wh/kg，难以满足长距离飞行需求
    + 安全和可靠性问题，应对复杂低空飞行环境和突发状况时的性能仍待提升（安全、可靠不如传统航空运输）
        + 无人机的避障、降噪等能力不足，限制了应用范围
+ 成本因素
    + 研发与生成成本高，需要大量资金投入，核心零部件、新型电池材料研发成本高
    + 运营与维护成本高，低空飞行运营成本高，需要完善的基础设施（目前不足），如通用机场、充电站。飞行器的维护和保养成本也较高
    + 产品价格高，受技术和成本因素，市场价格仍高
+ 市场因素
    + 应用场景有限，集中在农业植保、物流配送、应急救援，这些领域上尚未充分激发
        + 2022年我国通航飞行器的利用小时量仅为美国的4.5%
    + 商业模式不成熟，商业模式和盈利模式仍处于探索阶段，尚未形成稳定的市场格局
        + 无人机配送的单票收入比较低，需要规模效应支撑
    + 公众认知和接受程度低，安全、性能、噪音
+ 政策与监管因素
    + 空域管理限制，空域管理治理水平待培养，低空空域资源开发处于初级阶段、管理滞后，难以满足低空经济发展
        + 2024年低空飞行事故中，23%与空域协调冲突有关
    + 适航认证标准滞后，标准不完善、市场准入和推广受限
    + 安全监管不足，监管体系和技术手段滞后，难以应对飞行中的安全风险
+ 基础设施因素
    + 通用机场不足，数量有限、地面配套设施缺乏，低飞器起降和运营效率受限
    + 充电和维护设施不足，低飞的充电桩、维修设施，便利性和经济型受限
+ 环境与社会因素
    + 安全和隐私问题，人口密集地区的安全和隐私问题，如无人机 黑飞
    + 噪音

## 磁悬浮和低飞何时爆发？

### 汽车行业
1908年，福特T型车 开启大规模生产汽车的时代，被认为是汽车行业的起步阶段；
2050s，战后经济复苏，汽车需求大幅增长，汽车行业的快速发展期。


2001年，中国加入WTO，汽车市场快速开放，外资车大量涌入，汽车市场井喷。
2009年，中国汽车产销量突破 1000万辆，超过美国。
2010年，新能源汽车兴起，并得到政策支持。
2020年至今，新能源汽车成为主流，中国市场产销占重要地位。

### 高铁
1960s，日本新干线，世界第一条商业运营的高速铁路，高铁时代开启。
1980s，欧洲 法德意相继开通高铁。
2004年，韩国开通KTX。
2007年，中国CRH开通，此后高铁快速扩张（2016年 1.9万公里，2020年 3.79万公里，全球最大高铁网络）。

2010s，沙特、土耳其、摩洛哥陆续开通。2021年 全球高铁总长 5.95万公里。

2025年，中国高铁总里程 4.55万公里，约占全球的60%，而美国不到1000公里。

磁悬浮、超级高铁仍然是技术不成熟、成本高、需求低、风险大的项目。
