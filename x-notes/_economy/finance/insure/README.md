# 保险
投保人按合同约定，向保险人交付保险费，保险人按合同约定履行保险义务
## 分类
### 按标的不同
+ 财产险 一次性或分期缴纳，报销型；按标的估算价值乘以费率计算，可分期付款。
    + 财产损失险
        + 车险
        + 快递险
        + 房子火险/水险/被盗险
    + 责任保险
        + 车险中的第三责任保险
        + 电器厂商的产品责任险
        + 企业给雇员的雇主责任险
        + 航空延误险
        + 熊孩子险
    + 信用保证险 企业购买，违约险
+ 人身险
    + 社会保险 （社会强制险）个人实际收入及企业按比例按约缴纳，报销型&给付型；
        + 养老保险
        + 医疗保险
        + 工伤保险
        + 生育保险
        + 失业保险
        + 农村养老险

## 财产险的保险补偿原则：
1. 损失补偿原则，损失多少，补偿多少，以保险额度为上限
2. 重复保险分摊原则，多份保险，各家保险公司分摊赔偿，多投没用

## 社会保险
国内各地发展不均，收入不同，缴纳的社保基数和金额都不同，社会保险只有在缴费地区才可享受。国家正努力消除这个不均问题，尤其是医疗保险报销。

## 商业保险
商业保险资费贵，种类多且合约复杂，尤其是人身商业险。
社会保险覆盖范围不全，保障金额不足（还是会因病致穷、因意外致穷）。
### 理赔方式
+ 给付型，保险事故触发时，一次性或分批给付约定额度。
+ 报销型，按保险事故实际支出或损失支付，有些医疗保险可以保险公司直接付给医疗机构。
+ 津贴型，赔付被保人不能工作的损失及因需住院治疗的间接费用的损失
### 理赔范围
+ 疾病险  
1.工资收入损失；
2.业务利益损失；
3.医疗费用；
4.残废补贴；
5.丧葬费及遗嘱生活补贴；
a.一般不包括意外伤害；b.又可分为重疾和轻症；c.一般是给付型；
+ 医疗保险
社保医疗保险的补充。如补充医疗、中端医疗、高端医疗，或门诊医疗、住院医疗、生育保险。一般是报销型。
+ 收入保障保险
意外伤害或疾病导致被保人不能工作的保险，一般是固定期限固定额度给付型。
+ 意外伤害险
对残疾标准分级别（行业标准），残疾或身故都是给付型。特别的有意外伤害的治疗费用是报销型
+ 人寿保险
定期寿险、终身寿险、两全型保险、年金保险。全部是给付型。
寿险不被计入遗产税。
定期寿险，约定期限内事故（全残或身故）发生，则按约定赔付。
终身寿险，保险人身故或全残或生存至100岁（部分没有100岁规定）赔付，即肯定会赔付。
两全型，约定期限内，如果身故则赔付保险金，生存则赔付较少。
年金险，一段时间持续投保，另一段时间领取保险金。一般用于养老或孩子教育储备。如果身故，会赔付保险金。一般都会附加万能险，一种理财账户，与银行存款一样安全，收益率略高。
### 缴费方式
一般分为年缴、定期年缴、趸交。
年缴，买一次性保险，保障当年责任，到期续保。
固定年缴，每年缴纳，直到一定年限，或续费降低，或豁免。
趸交，一次性付清固定年缴的费用，整体费用低，但影响投保人现金流，且一般不享受豁免条款。
