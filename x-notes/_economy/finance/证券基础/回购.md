# 回购 Buy-back
产品回购，又称补偿交易Compensation Trade，原指交易的一方在向另一方出口机器设备或技术的同时，承诺购买一定数量的该设备或技术生产的产品。
产品回购的交易期限较长，有时长达5-10年。

股票回购，指上市公司用现金等从股票市场购回其发行的一定股票的行为。起到防止兼并与收购，提升股价，减少经营压力，重新资本化的作用。


正回购 Sell Repo
，一方以一定规模证券质押融资，并承诺在日后再购回所质押证券的交易行为。

逆回购
，一方收取有价证券做质押，融资给对方，并在未来收回本息的交易行为。

+ 正回购后获得资金的投资回报高于所付出的利息，则是盈利的，否则是亏损。
+ 回购到期，可以用现金还款，或债券卖出偿还。
+ 回购可以续作，即到期后延续抵押，部分券商为规避风险不允许
+ 回购可以套作，即融资后买入债券，循环融资买入，部分券商不允许
+ 回购打新股T+2日一般不用再做回购
