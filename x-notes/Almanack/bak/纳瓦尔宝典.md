The Almanack of Naval Revikant
---
A guide to wealth and happiness

每个人都拥有资源，但不是所有人都能善于利用自己的资源，创造财富、保持健康、

+ 靠出租自己的实践是永远无法致富的
    + 人生努力的目标是努力提高自己的独立性，而不是升职加薪
    + 人生追求的财富应该是睡觉时也能带来收入的企业和资产
    + 向社会提供其所需，换取财富
        + 石油富了洛克菲勒，汽车富了亨利福特
        + 你能为社会提供什么？在你的技术和能力范围内，轻松地提供
    + 方法是把 自己 产品化
        + 自己提供专长，产品化提供杠杆效应
        + 找到自己的天赋所在，积累专长；没有天赋的地方，不要去动
        + 成为自己（找到自己的专长），积累专长，运用专长，找到杠杆，利用杠杆
        + 付出时间工作，不一定能获取到财富
+ 杠杆
    + 利用了杠杆 VS 没有利用杠杆
        + 人生时间和精力有限，杠杆则可以放大个人的产出
    + 杠杆有多种：劳动力、资本、代码或媒体
        + 劳动力 -- 让别人给你打工
            + 管理他人是件 复杂、难度高的工作，需要高超技巧，有反噬危险
        + 资本 -- 投资，风险投资
            + 有难度、需要一定技能
            + 巴菲特
        + 复制边际成本为0的产品 -- 最值得研究的、最重要的杠杆
            + 新的时代出现的，普通人也触手可及的
            + 包括书籍、媒体、电影、代码
            + 使用和获得都无需获得他人的认可
                + 大部分代码不需要许可，即可复制
            + 亚马逊、谷歌、脸书、微软
    + 特点
        + 要使用劳动力杠杆，就得有人决定追随你。
        + 要使用资本杠杆，就得有人给你提供资金，你再去进行投资或开发产品。
        + 而编程、写书、录播客、发推特、拍视频这些事情不需要经过任何人的许可。
+ 如何使用杠杆
    + 增强自己的判断力、提升决策技巧
+ 幸福
    + 幸福不依赖于财富
