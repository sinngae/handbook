Just Do It
---
误区定式
+ 信息差、思维的定式（思维的惯性）导致计算不出达成目标的困难、或计算出的困难很大，导致没有信心
    + 信息差
        + 未知 => 困难
    + 思维定式
        + 将思维局限在想象之中
    + 行动力会由于一次次、一层层的思维定式包围下减弱
        + => 逐渐成为“思想的巨人”
        + => 情感上，越来越被动；而不是去承担风险，敞开心扉

打破误区和定式
+ 打破恐惧
+ 结构化分解
    + 问题分析
        + 有哪些困难 => 我要怎么做
    + 消除未知，尽调（）
    + 成本风险
        + 风险过高 -- 不切实际
        + 风险过低 -- 消磨时间、失去兴趣
        + 了解成本、接受风险
    + 步骤分解
        + 闷头努力，看上去用工、事倍功半、没有效率
            + 基于时间导向的思维，一个长时间的反馈周期的目标
        + 大目标拆解 -- 小目标
            + 反馈周期缩短，强多巴胺回路
+ 总结
    + 人们倾向逃避自己不喜欢做的事情，而逃避所积累的负面负担，远超过正面解决的痛苦。最终崩溃
    + 误区定式，不只是完成事情，也是为了达成内心的平静。
    + 学会享受完成目标的成就感，与自己相处
    + 最终得到从前得不到的东西
    + 不要停留在想象层面
    + 点亮炬火，照亮前路；直面人生，与自己和解。
