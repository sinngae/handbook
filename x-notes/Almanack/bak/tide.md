# 2022 layoff tide
行业何去何从，个人何去何从，35岁何去何从？

+ 资本市场回归理性？还是解禁潮，资本获利出逃？资本避险出逃？
+ 国内环境变化
    + 反流量垄断法出台 =》 合规经营
    + 倒逼IT行业技术创新，而不是内卷业务（比如社区买菜，或所谓金融创新）
    + 鼓励深层次技术创新
        + 国内乏善可陈的技术创新
            + 技术创新的星辰大海更令人心潮澎湃
+ Web技术 软件工程技术门槛降低，大量跨行业、跨专业的人卷入
+ 市场薪酬体系回归正常？
    + 薪资与职位数量、同行业利润相关
    + 企业利润和收支挂钩，而不是风险投资
