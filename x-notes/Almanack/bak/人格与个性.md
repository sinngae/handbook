Personality 人格
---
性格 是一种个体内部的行为倾向，具有整体性、结构性、持久稳定性等特点。性格 是心理学上对个人行为、态度提供统一、内在的解释。

# MBTI
MBTI包裹着糖衣、使用褒义词汇，给人带来愉悦感，并无可考依据。
MBTI所使用的词汇确实可以做为一种技巧，可以作为自我探究的话题，不能作为评价标准。


1. 个人与外界相互作用的程度，以及个人能力容易被引导到何处
    + 外向型 Extravert
        + 关注自己如何影响外部环境
        + 将心理能量和注意力聚集在外部世界和与他人的交往上
            + 聚会、评论、聊天
            + 分享，说的多，听的也多
    + 内向型 Introvert
        + 关注外部环境变化对自己的影响
        + 将心理能量和注意力聚集于内部世界，注重自己的内心体验
            + 独立思考、看书
            + 避免成为注意的中心，听得多，说的少
2. 个人注意到的信息类型
    + 感觉型 Sensing
        + 感觉器官获取的具体信息
            + 看到的、听、问、尝、触摸到的
            + 关注细节、喜欢描述、喜欢使用和琢磨已知的技能
    + 直觉型 iNtuition
        + 事物的整体和发展变化趋势
            + 灵感、预测、暗示、重视推理
            + 重视想象力和独创，喜欢学习新技能
            + 容易厌倦，喜欢使用比喻，跳跃性地展现事实
3. 个人做决定和得出结论的方法
    + 思考型 Thinking
        + 重视事物之间的逻辑关系，喜欢通过客观分析做决定性评价
        + 理智、客观、公正
    + 情感型 Feeling
        + 以自己和他人的感受为重，将价值观作为判定标准
        + 对 行为对他人的感受的影响 敏感
        + 认为圆通和坦率一样重要
3. 个人喜欢较为固定的方式生活（或做决定、获取信息），还是更自然的方式
    + 判断型 Judging
        + 喜欢做计划和决定，愿意进行管理和控制
        + 希望生活井然有序
        + 重视结果（强调完成任务）、按部就班、有条理、尊重时间期限
    + 感知型 Preceiving
        + 灵活、试图去理解、适应环境
        + 倾向于留有余地，任事情自由发展
        + 重视过程、随信息的变化不断调整目标
