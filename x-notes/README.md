# 概述
技不压身，但不能都是屠龙之技，好的知识学习，应该是有前瞻性的。
抱成团的筷子不容易被折断，有机组合在一起的知识领域，能带来1+1>2的效应。

终身学习：知识不是按学科划分的！

做一个贪婪的学习者：每周至少花5个小时有意识地学习。
做一个博才多学的人：擅长三个领域，有机组合三个领域，并成为前1%的人。

核聚变能源/字体设计/科学家传记/医生的回忆录

学习不是为了工作，学习就是工作最重要的部分，是工作核心，永远不能放弃的事情。

错误的观念：
+ 学科是对知识分类的最佳途径
+ 学校是完成了大部分学习
+ 必须选择一个领域并专注于它
+ 刻意学习只是生活的一个选项
