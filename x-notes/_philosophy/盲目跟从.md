Idiot Flow
---
公司里有很多人，闲的闲死、忙的忙死，为什么会这样呢

工作会自动膨胀
+ 如果事件充裕，人们就会放慢工作节奏（就像走起来，而不是跑起来，听起来有些卷），或者增加其他项目以用掉所有的时间
    + 工作可以被扩展到无限多，没有收敛
    + 工作总会拖到最后一刻才会被完成
+ 对于个人，无用的事情塞满时间，导致工作效率低下
+ 对于组织，能力更差的人塞满组织，团队战斗力总体下降
    + 每个人都招聘比自己差的，企业只会越来越差（人的成长呢？工作几年了，还会成长么？人才是企业竞争的关键）
        + 应该跨层级招聘？乔布斯为避免公司上下充斥着二流人才要求的
    + 中小企业应该根据自己的发展，选择务实的管理模式，更不能犯大公司的病

企业和个人
+ 公司是营利性组织
+ 个人和公司必须是双赢
+ 个人需要认同公司的理念，并给公司创造足够价值，为个人发展而工作

二十世纪西方文明的三大发现
+ 墨菲定律
    + 抱着侥幸心理，明知某事不会有好结果，依然闭眼去做
+ 帕金森定理
    + 当领导者的能力不强，一般会选择能力不如自己的人来当助手（而不是退位让贤、或找能力强的人来辅助），最终导致公司成为人浮于事、相互扯皮、效率低下的体系
    + 又称，组织麻痹症、官场病、大企业病、金字塔上升现象（层级变多）、官僚主义
    + 在行政管理中，行政机构会像金字塔一样不断增多层次，行政人员不断膨胀、每个人都很忙，但是整体的组织效率越来越低下
+ 彼德原理
    + 在组织中，总是提拔某个职级的优秀员工，使其晋升到超过其能力的职位上，且不能发挥其特长。

不要抱着侥幸心理，做自己能力范围之外的事情，做不切实际的幻想。

# 应对

帕金森定律发生的条件：
+ 权力是临时的，所以惧怕他人竞争
+ 组织有实力无限扩大，多一人少一人无所谓的心态

现实中还是有强将手下无弱兵的，强将是值得跟的领导，自己也不要做个弱兵。

个人增效
+ 时间管理
    + 时间记录 
        + 基于统计数据的思考
        + 预留可控和灵活的时间段
    + 任务清单
        + 每天只重点做三件事，哪怕其他任务没有完成
        + 将80%的精力放到20%的重要事项上

公司增效
+ 平台化管理
    + 引入外部团队竞争
+ 清晰的分工、以及基于分工的协作
    + 细分工作上的leader的权威的建立
    + 细分工作之间协作的规则的建立
+ 领导能力，更多体现在理念、期望到实践的顶层管理
+ 相信分工，但要保持知情
    + 结果不清晰的时候，不能立马有反应
