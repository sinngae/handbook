# 

如今的社会是一个外向型的社会，整个社会舆论其实更偏向于外向型的人，所以它更鼓励大家社交、开拓、尝试等一些外向型的人所具有的特质，但物极必反，这些舆论同时又反过来加深了大家对于内向型的人的偏见，包括内向型的人自己对自身的怀疑。

比如在工作中，很多内向的人却总是会抱怨自己性格太内向，不太能融入团队等等。但是在我看来，这个问题的症结在于内向者没有看到和发挥自身性格特质所带来的优势，而一味只把注意力放在自身的短板上所造成的。

在心理学上来说，这两种类型的人都是各有优缺点的，没有谁比谁更高级更优秀的说法，这些偏见和压力大多都是社会舆论的渲染和传播造成的。我们应该学会看清自己的优缺点，接纳自己，在工作生活中扬长避短，充分发挥我们性格上的优势和天赋来帮助我们成长进步。

# 内外向是天生的
从分析心理学的角度来说，内外向（专业来说应该叫内外倾）是一个人天生就具有的两种基本态度，也就是说，一个人生下来，他是内向还是外向的人就已经确定的了。不过，每个人其实都是同时拥有这两种基本态度的，只是有一种态度是一个人更倾向和更喜欢使用的，这个时候就会形成一个态度类型——内倾型和外倾型。

换句话说，内向的人也有外向的一面，也有渴望社交的时候，只不过一般来说，内向的人只会在熟悉的环境中表现地更外向、更健谈，同时他也会比外向的人表现得时间更短一点。

比如在职场上，内倾者往往融入团队所花的时间会比外倾者要长，与团队相处时间也更短，这是由于他们在进行了（自认为）足够的社交以后，他们需要退出来独处，恢复心理能量，这样他们才能保证往后能有更好地精力去处理与团队的关系。

所以内倾者不要觉得自己不合群，这只是你们最自然地与别人相处的方式而已，况且我们在职场上是来工作解决问题的，不是来交朋友的，放宽心即可。

相对应地，外向的人当然也会存在有内向的一面，他们也需要独处，来平衡自己与外部世界的关系，去确认自身的价值，不至于迷失在外部世界中。所以这两种态度倾向都是人所必须的，一个负责处理外部世界的关系，一个处理内心世界的关系，一旦某一种态度缺失，人就会出现问题。

而由于内倾型的人是更关心自己内心世界的，他会将自己的心理能量和注意力大部分投注于自己的内心世界，所以内倾者们往往喜欢精心编构他们的思想和观点，但也更容易无视外在的现实，这其实既是优势也是劣势（凡事皆有两面性）。

**其最大的优势在于，它使内倾者能够比外倾者更容易摆脱外部干扰和感性的限制，使其思想发展和对事物的洞察更加地抽象、更接近事物的本质。**因此相对于外倾型的人，内倾者往往能够更专注，更容易在一个领域成为专家，甚至是大师。

# 如何摆脱职场不自信
但是现在的问题在于，由于商业社会是一个具有非常明显的扩张性和侵略性的外向型社会，商业组织作为这个社会中最重要的组成部分，天然会对内倾型人造成思想和行为上的压迫，并放大他们身上的缺点，让他们觉得是自己出了问题，而不是本身环境的问题。

比如职场上的不自信。

内倾型人会特别容易产生不安全感和危机感（不自信），所以当他在做着自己不够专业的工作时，会很容易变得不自信、缺乏安全感和焦虑，这又进一步影响了他的发挥和别人（同时或者客户）对他的感受评价。

其实外倾型的人在业务水平上可能跟内倾型的人掌握的一样，但是由于外倾型人天生自带的自信光环，觉得自己什么事都能干成，简直是自信得一匹，自然给同事和客户的感觉会更好、更专业，但其实两者的专业能力并无区别。

所以这个时候，要接近内倾者在职场上不自信的问题，需要做的就是努力提高自己的专业能力（当然也还有语言表达能力）。当内倾者的业务水平达到了专业水准的时候，自身解决专业问题的能力也会逐渐得到提升，这个过程往往也会伴随着周围人的认同，于是内倾者的自信便会慢慢建立起来。

# 写在最后
总的来说，**内倾型的人通常在从事一些有足够深思熟虑的时间和空间的工作时感到最自在，而且能最好地发挥其优势。**他们通常喜欢反省或者解释自己的一些过往经历，行事相对谨慎，能够妥善制定未来的行动计划。

虽然他们相对于外向者表现得难以解决或者显得沉静缄默，不喜欢出风头，但是他们也可以做到**更精确、更富于远见、更客观或者更敏锐**。


# 总
其实内向性格并不是一种缺陷，相反内向性格的人通常拥有外向性格的人所不能具备的优点。很多事业有成的科学家、企业家往往都是内向性格的人。以为内向性格的人更容易沉浸在自己的世界里，更容易集中精神去做一件事。同时内向性格的人精神世界更加丰富，更容易注意到其他人注意不到的细节。当然，这些优点运用不好也会成为缺点，比如：过于丰富的精神世界很有可能会导致内向性格的人胡思乱想，进而导致自卑或者焦虑。

内向性格的人需要通过独处来补充在社交时消耗的精力，不然会导致内耗严重，无法继续学习和工作。由于有过高的责任心，很容易陷入自责的情绪中。

那么如果你是一个内向性格的人，应该怎么样正确的利用好自己的内向性格呢？

首先，我们应该改变自己的心态，内向性格并不是一种性格缺陷，内向并不妨碍我们取得成绩，只是你需要改变自己的想法，正视自己的内向。提高自信心把自卑和否定自己的时间都用在提升自己中去。

其次，很多时候内向的人也需要被迫去进行社交，内向性格的人可以从提升自己的沟通能力开始。多试着与熟悉的人练习交流，试着将你的想法完整地表述出来，在这样地对话中进一步提升自己地沟通能力。如何你还觉得提升得不够快，可以试着结交更多的朋友，聊天多了，沟通能力自然就上去了。

最后，有一些小技巧可以帮助我们内向性格的人活得更加轻松。要适量的放过自己，不要强迫自己去做不符合个性的事情，也不要试图去改变自己的性格。最重要的是内向性格的人要学会去自我实现，在不断获得进步的过程中，我们也能放下对自我的怀疑和焦虑，去做最真实的自己。
