无限回归 Infinite Regression
----
科学基于可证伪实验，没有辩论的空间。
可以辩论的问题必然不是（纯粹意义上的）事实判断，核心是价值判断。
价值判断的空间里，能讲道理的很少。

# 明希豪森三重困境
1. 无限倒退

为了证明一个命题p=>q，需要引入一个前提，接着又引出另外一个，没有终结，形成没有结论的现象。

2. 循环论证

A=>B 需要 B=>C + C=>A的循环论证

3. 论证终结于某个信念、信仰

一切都是上帝的安排。。

+ 人类的语言特点
    + 延宕 - 可以不停地引入黏连关系的概念，来拖延结论
    + 不精确 - 具体的语言对不同的人又不同的认知边界，实际是个约定的大约的概念。
        + 扣概念 => 延宕 造成无限倒退
        + 无限倒退 => 转移到自己能接受的逻辑框架内，造成自洽的循环论证
+ 人的信念和信仰
    + 信念是长期的社会生活形成，很难短期打破
    + 不同信念的人很难达成共识，最终就会 终结论证

# 保守主义的三个命题
注意：并无实据，也无实据证明不会，只是价值倾向保守。
1. 悖谬论

这样做会起反效果，不是你想要的吧。

2. 无效论

这样做不行的，不如不做，再想想其他办法。

3. 危害论

这样做看似有效，但要小心，有很大风险，值得么？

辩论的核心是价值判断和价值阐述，并且辩论更趋向于讨论非科学性的、难以证伪的相关内容。如此，辩论与其说是双方为了真理而进行逻辑上的交锋，不如说是双方为了证明自己已形成的价值观或自己的持方而进行的自证过程。

价值判断无法证伪，社会实验无法有效复现。
