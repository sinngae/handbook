虚无 Nihility
----

# 克尔凯郭尔
+ 虚无是因为现代社会和文明对个体独特性的压制，导致个体意义的丧失
+ 虚无是一种绝望，个体在面对生存的有限性和无限性 即矛盾又挣扎，进而感受到生存的荒谬和虚无
+ 克服虚无，唯有“信仰之跃” leap of faith，理性终将引向绝望和虚无，而信仰则超越理性的限制、赋予生命意义。
+ 个体在绝望中，向“上帝”伸出双手，从而跨越到永恒彼岸


## 生存三阶段
1. 审美阶段，个体沉溺感官享受，终将虚无
2. 伦理阶段，个体服从道德行为寻找意义，仍可能陷入绝望
3. 宗教阶段，个体通过信仰实现对虚无的超越

# 尼采
+ 传统价值体系（基督教、科学理性）是无价值的，他们否定了生命的本能和现世的价值。
+ 传统价值消解，留下真空、意义缺失，进而人们失去生活的方向和目标、陷入虚无
+ 科学理性的核心概念（客观性、真理、自在等）是错误的 或 不存在的。
+ 主张摆脱旧价值束缚，创造复合生命本能和强力意志的信价值
+ 权力意志是生命的本质，是推动生命不断追求卓越和自我超越的力量
+ 永恒轮回则强调生命的无限循环和重复，人应当在有限的生命中追求卓越、实现自我价值
+ 超人，超越传统道德和价值束缚的理想人格，具有强大生命力和创造力，勇敢面对虚无、创造属于自己的价值。

## 弱者的道德 VS 强者的道德
强者阶层的主人道德起源于贵族阶级自身的优越感和自我肯定，强调个体的独立、自主和力量，核心是“区分好坏”
+ 自我肯定和骄傲，认定自己的行为和品质是好的，否定不同的行为为坏的
+ 力量和主动，崇尚力量、勇气和主动精神，强调个体的自我实现和超越。
+ 等级秩序，明确的等级秩序，强者统治弱者是自然秩序

弱者阶层的奴隶道德起源于对强者压迫的反抗和怨恨 进而对强者行为的否定，核心是“区分善与恶”
+ 自我否定与谦卑，软弱、谦卑和忍耐为“善”，强者力量和优越性为“恶”
+ 反动与怨恨，奴隶道德是反动的道德，否定强者价值来确立自身价值
+ 群体主义，强调群体的平等和互助，反对个体的优越性

基督教是奴隶道德，宣扬谦卑、忍耐和来世幸福，麻痹人们的反抗意识，使人称为弱者、安于现状。这种道德观扭曲了人类对幸福和快乐的追求，导致个体和社会的退化。


## 权力意志 will to power
+ 权力意志是生命不断追求自我肯定和自我超越的动力，是生命力的体现。
+ 权力意志反对消极的否定生命的态度
+ 权力意志对抗虚无，个体重新赋予生命意义，创造新的价值
一切都是权力意志，哲学是最强的权力意志。

## 永恒轮回
表达的是人应该热爱生命，期望生命永恒且轮回。

1. 生命的有限性，但仍然有意义
2. 因为生命有限，所以才有意义；无限反而无意义
3. 热爱生命，用 永恒轮回 肯定生命。

生命和世界在时间中不断重复（不是线性向前的）。
+ 每一个瞬间都是永恒的，也是循环的
+ 永恒轮回，所以个体应该肯定生命，赋予生命意义，个体的每个选择和行动都具有永恒的意义，个体应该在重复的生命中找到意义。
+ 哪怕生命重复、一点变化也无，也应热爱生命



## 总结
尼采的哲学不能体悟，不是实践的哲学，近似文学


# 叔本华

+ 世界和人生的本质是痛苦和虚无的，因为生命的本质是意志，意志是盲目的、无目的的、无止境的欲望冲动，推动着生命不断追求满足，而这满足是短暂的、又去满足新的欲望。
+ 幸福是短暂幻象，痛苦是人生常态
+ 时间流逝，一切事物不断变化，人生的遭遇无常
+ 终将死亡，意志结束
+ 艺术可慰藉痛苦，进入审美状态，获得短暂的宁静和幸福
+ 否定意志、禁欲，抑制欲望、减少痛苦
+ 哲学思考，认知虚无、进而超脱

# 萨特
+ 虚无是人自由和意识的体现，是存在的一个特征
+ 人应当自由选择、承担责任，赋予生命以意义

# 加缪
+ 严肃的哲学问题只有一个，就是自杀
+ 人生本质是荒诞的，源于 人类对意义的追求 与 世界无意义 的冷漠之间的矛盾。
+ 人类生活在一个冷漠的宇宙中，宇宙对人类的存在和追求毫无回应。
+ 人类苦苦渴望生命的意义和目的，但是世界却是无意义的冷漠状态。
+ 上述矛盾导致荒诞感的产生，但这荒诞不是一种绝望，而是一种清醒，是人类必须面对一个没有预设意义的世界。
+ 加缪主张通过反抗来赋予生命意义，反抗荒诞是人类唯一的选择。这种反抗表现在对生活的积极投入和对自由的追求。
+ 西西弗斯可以在推石头的过程中找到幸福，源于他对荒诞清醒的认知和对命运的反抗。
+ 荒诞是人意识到自己的孤独和人类共同的困境，这种共同体验可以促使人类团结起来反抗荒诞，具有在荒诞世界寻找意义和价值的可能性。

+ 主张通过实践和革命来克服虚无主义，而不是陷入纯粹的哲学思辨


## 个体的异化

# 佛学
+ 空 不是虚无，而是一种对世间万物因缘和合、无常无我的深刻理解。
+ 空 不是事物不存在，而是事物没有独立、永恒的实体
+ 色即是空，空即是色，空色不二，事物相互依存、无常
+ 缘起，一切事物因条件而聚合而生、因条件的消散而灭。所以“性空”，事物本质是空的，没有自性
+ “中道”，事物既非绝对的“有”，也非绝对的“无”，而是动态的、相互依存的
+ 佛学的“空” 是帮助人们摆脱对事物的执着、对永恒不变的执着，进而超脱和智慧的境界。

## 空色不二
